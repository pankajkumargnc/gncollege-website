## Integrated Skills Catalog (Guru Nanak College Website)

The following skills from ECC have been curated and integrated into `.agents/skills/` for use by the GNC engineering team agents:

### 1. Frontend & Design (Assigned to `ui-agent`)
- `frontend-patterns`: Component boundaries, state placement, rendering performance.
- `frontend-design-direction`: Establishing clear aesthetic direction and layout harmony.
- `design-system`: Token hierarchy, spacing, typography, and cohesive component design.
- `make-interfaces-feel-better`: Polish, micro-interactions, and visual delight.
- `liquid-glass-design`: Modern translucent, frosted-glass, and elevation styling.
- `motion-foundations`: Core motion principles, transitions, and timing functions.
- `motion-advanced`: Choreographed, spring-based, and layered motion systems.
- `accessibility`: WCAG 2.1/2.2 AA compliance, keyboard navigation, and ARIA roles.
- `browser-qa`: Cross-browser, responsive, and visual QA verification.
- `react-patterns`: Modern React 18 patterns, hook composition, and clean render trees.
- `react-performance`: Memoization, re-render minimization, and lazy loading strategies.
- `vite-patterns`: Vite bundling, code splitting, dynamic chunks, and asset handling.

### 2. Backend & Data (Assigned to `backend-agent`)
- `backend-patterns`: Cloud service integration, resilient data pipelines, and error boundaries.
- `api-design`: Clear query schemas, REST/RPC conventions, and pagination standards.
- `database-migrations`: Data transformations, schema migrations, and field backfills.
- `error-handling`: Graceful error recovery, fallback data, and retry policies.
- `admin-portal-patterns`: *(Project specific)* Firestore CRUD, reactive listeners, and admin portal architecture.

### 3. Security (Assigned to `security-agent`)
- `security-review`: Proactive code and configuration audits for security flaws.
- `security-scan`: Systematic detection of injection vulnerabilities, leaked secrets, and misconfigurations.
- `security-bounty-hunter`: Red-teaming and aggressive edge-case vulnerability hunting.
- `production-audit`: Pre-deployment hardening, environment variable audits, and header checks.
- `repo-scan`: Static repository analysis for secrets and high-risk dependencies.

### 4. SEO & Content (Assigned to `seo-agent`)
- `seo`: Search engine optimization, meta tags, Schema.org JSON-LD, and indexing best practices.
- `content-engine`: Structured educational content generation and batch authoring.
- `brand-voice`: Consistent institutional tone, academic credibility, and messaging standards.
- `article-writing`: Clear, engaging educational articles, announcements, and notices.
- `marketing-campaign`: Campaign structuring for admissions, academic events, and college achievements.

### 5. Review & Testing (Assigned to `review-agent`)
- `react-testing`: Component testing, React testing best practices, and hook validation.
- `tdd-workflow`: Test-driven development red-green-refactor cycles.
- `e2e-testing`: End-to-end user journey validation and flow verification.
- `plankton-code-quality`: Strict code cleanliness, dead code removal, and formatting standards.
- `verification-loop`: Continuous automated check loops to verify fixes before sign-off.
- `coding-standards`: Consistent conventions, naming, and architectural alignment.
- `delivery-gate`: Strict checklist-based gatekeeper before any code is marked complete.

### 6. CTO Orchestration & Strategy (Assigned to `cto-agent`)
- `agentic-engineering`: Multi-agent coordination, specialized delegation, and context management.
- `intent-driven-development`: Translating developer requirements into verified functional deliverables.
- `architecture-decision-records`: Formalizing key technical decisions with trade-offs.
- `plan-canvas`: Visualizing execution plans, dependency graphs, and parallel tracks.
- `plan-orchestrate`: Scheduling and orchestrating complex multi-phase development plans.
- `continuous-learning-v2`: Capturing lessons learned and updating agent memory systematically.
- `context-budget`: Monitoring token consumption and preventing context overflow.
- `git-workflow`: Clean branching, atomic commits, PR packaging, and GitHub Pages release flow.
- `dev-team`: Simulating multidisciplinary engineering team reviews and retrospectives.
- `code-tour`: Guided architectural tours through project components.
- `codebase-onboarding`: Fast-tracking agent context on the GNC College codebase.
- `documentation-lookup`: Efficiently locating relevant guides, specs, and API docs.
