## 📐 The Golden Rules of Maintenance
*Strict directives to ensure the website never loses its premium feel.*

### Rule 1: No Emojis for Core UI Elements
OS-rendered emojis have been permanently stripped from primary navigation and action buttons to avoid inconsistent rendering across iOS, Android, and Windows. 
**→ Golden Rule:** If you need an icon, you MUST import it from `lucide-react` (e.g., `<Newspaper />`, `<User />`).

### Rule 2: Strict Dynamic Viewports (`100dvh`)
Mobile scrolling layouts often glitch because mobile browsers have dynamic URL bars.
**→ Golden Rule:** NEVER use `100vh` for full-height containers. The entire project has been ported to `100dvh` (Dynamic Viewport Height). Maintain this unit for all future screen-filling wrappers.

### Rule 3: ESM Hoisting & Lazy Loading Scoping
First Contentful Paint (FCP) has been optimized by placing heavy components on background threads.
**→ Golden Rule:** In `App.jsx`, all standard `import` statements MUST be declared at the absolute top of the file before any `const Component = lazy(...)` declarations. Reversing this order will crash the Vite build and sever React's Fast Refresh (`useState` null errors).

### Rule 4: Zero Fallback Images (Strict WebP)
The payload size has been successfully slashed.
**→ Golden Rule:** Any future gallery uploads, staff profile pictures, or banners MUST be compressed to `.webp`. Do not upload transparent `.png` or heavy `.jpg` files.

### Rule 5: WCAG Accessibility Safety
**→ Golden Rule:** Never remove `aria-hidden="true"` from decorative icons. Never remove `sr-only` classes from search inputs. Doing so will blind screen readers and drop the Google Lighthouse Accessibility score.
